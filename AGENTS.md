# Modelo de projeto

Repositório do modelo que os projetos do usuário seguem (veja o `README.md`). Converse em português.

- Mudança no bloco fixo (`base/bloco.md`) vale para todos os projetos no próximo `modelo atualizar`: só com o ok do usuário.
- Antes de dizer que algo está pronto, rode `./testes/rodar.sh` (precisa de internet; leva uns 2 minutos).
- Decisões em rodadas de perguntas numeradas com recomendação (skill `grilling`); TDD com os pontos de teste combinados antes (skill `tdd`).
- Commits em Conventional Commits, em português, terminando com a linha `Co-Authored-By` do agente. Push só quando o usuário pedir.
